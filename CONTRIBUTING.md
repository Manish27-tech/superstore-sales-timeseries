# Contributing

## Setup

```bash
python -m pip install -r requirements-dev.txt
python run.py all
python -m pytest -q
```

## Rules

- Run `python scripts/check_artifacts.py` before opening a pull request.
- Keep ruff clean: `python -m ruff check src dashboard run.py scripts tests`.
- Do not commit `data/raw/` or `data/processed/`; the dashboard feed in
  `data/dashboard/` is committed and regenerated by the pipeline.
- Every new figure must be numbered and referenced from `reports/REPORT.md`.
- If you change a number in the prose, regenerate the report with
  `python run.py report` rather than editing it by hand.
